# 旺财 (WangCai) - 宠物健康管理系统

“旺财”是一款专为宠物设计的健康数据管理应用。核心功能是帮助宠物主通过精准的“插值计算”追踪宠物的饮食摄入量，并提供体重、用药、排泄、零食等多维度的健康趋势分析。

## 核心功能

*   **智能饮食追踪**：采用独特的“双套插值”公式，精准记录宠物的进食与饮水数据。
*   **多维度记录**：支持体重波动、用药打卡、拉撒记录、零食记录。
*   **健康趋势分析**：提供周、月、年维度的可视化数据统计。
*   **云端同步**：基于 Supabase 的数据同步方案，支持多设备数据共享与备份。
*   **自动备份**：集成 WorkManager 定期将数据导出为 Excel 存放在本地空间。

## 技术方案

*   **UI 框架**：Jetpack Compose (Material 3)
*   **开发语言**：Kotlin (K2 编译器)
*   **数据持久层**：Room 数据库 (支持自动与手动迁移机制)
*   **网络与序列化**：Ktor + kotlinx.serialization
*   **数据可视化**：Vico Charts
*   **导出引擎**：Apache POI (经过精细的混淆与体积优化)

## 核心业务逻辑：饮食摄入“双套插值”公式

1.  **逻辑 A (未空记录)**：`变动量 = 电子秤新数值 - 上次记录总重`。
2.  **逻辑 B (空碗记录)**：`变动量 = 电子秤新数值 - 碗重`。
系统会自动持久化 `grossWeight`（总重），即使删除记录也能自动找回基准。
